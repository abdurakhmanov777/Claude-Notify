# Changelog

Все заметные изменения расширения **Claude Notify**.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [2.3.1] - 2026-07-26

### Изменено
- Убрано «Claude Code» из текста уведомлений: заголовок по умолчанию теперь
  `{project}` (было `Claude Code · {project}`), текст о завершении — «Запрос
  завершён» (было «Запрос в Claude Code завершён»). Если заголовок в итоге
  пустой (проект неизвестен), он не отправляется — ntfy подставит имя топика.

## [2.3.0] - 2026-07-26

### Добавлено
- **Уведомление, когда Claude показывает диалог выбора** (`AskUserQuestion`).
  Реализовано через хук `PreToolUse` с фильтром на этот инструмент — `Notification`
  для него Claude Code не шлёт. В текст уведомления подставляется **сам вопрос**
  (из `tool_input`); если его нет — запасной `waitingMessage`.
- Хук `PreToolUse` (matcher `AskUserQuestion`) добавляется командой «Claude
  Notify: настроить хуки Claude Code» автоматически.

### Изменено
- Значение `waitingMessage` по умолчанию — «Claude ждёт вашего ответа» (годится и
  для запроса разрешения, и как запасной текст для диалога выбора).

### Примечание
Чтобы заработало, выполните «Claude Notify: настроить хуки Claude Code» и
перезапустите сессию Claude Code (хуки читаются при старте сессии).

## [2.2.0] - 2026-07-26

### Изменено
- **Дедупликация стала точной, без гадания по времени.** Раньше повторы гасились
  по «окну N секунд», из-за чего два разных завершения в пределах окна могли
  слипнуться в один пуш. Теперь ключ дубля строится по **идентификатору запроса**
  Claude Code (`prompt_id`), а при его отсутствии — по `session_id` + размеру
  транскрипта. Разные завершения больше не склеиваются никогда; повторное
  срабатывание одного и того же события — гасится. Защита от дублей общая для
  всех окон (атомарный маркер по хешу ключа).
- Настройка `claudeNotify.dedupeSeconds` теперь означает «сколько секунд помнить
  отправленное событие» (по умолчанию `60`). Значение больше не является
  компромиссом — с точным ключом его можно держать большим без риска потерять
  уведомление. `0` — отключить.

### Как это работает
- Хуки теперь запускают крохотный помощник `~/.claude/claude-notify-hook.js`
  (его пишет само расширение). Помощник читает данные, которые Claude Code
  передаёт хуку, и кладёт в триггер имя проекта и идентификатор события. Хук в
  `settings.json` стал коротким: `node <скрипт> done`. Требуется `node` в PATH.
- Команда **«Claude Notify: настроить хуки Claude Code»** обновляет хуки под
  новый формат (и подхватывает как старые echo-хуки, так и новые).

### Примечание об обновлении
Выполните команду «Claude Notify: настроить хуки Claude Code» и перезапустите
сессии Claude Code. Старый echo-хук продолжает работать (расширение понимает и
его формат), но точный ключ доступен только с новым хуком.

## [2.1.1] - 2026-07-23

### Исправлено
- **Дублирование уведомлений.** Одно завершение запроса могло дать два пуша,
  если хук срабатывал несколько раз — например, когда открыто несколько окон
  и часть сессий Claude Code стартовала до обновления хуков (старый хук писал
  пустой триггер, новый — с путём проекта, отсюда два уведомления, одно
  с именем проекта и одно без).

  Атомарный «захват» триггера защищал лишь от того, что одну запись обработают
  два окна, но не от нескольких записей. Теперь добавлены:
  - склейка всплеска триггеров (короткая задержка перед отправкой, имя проекта
    из более позднего триггера побеждает);
  - общий для всех окон маркер-замок на диске (атомарное создание файла), так
    что в пределах окна дедупликации пуш уходит ровно один раз.

### Добавлено
- Настройка `claudeNotify.dedupeSeconds` (по умолчанию `5`) — окно защиты от
  дублей в секундах; `0` отключает её.

## [2.1.0] - 2026-07-23

### Добавлено
- Команда **«Claude Notify: настроить хуки Claude Code»** — сама вписывает хуки
  в `~/.claude/settings.json`: делает бэкап (`settings.json.backup`), не трогает
  чужие хуки, выбирает `bash` или `powershell` под систему.
- **Имя проекта в уведомлении.** Хуки теперь дописывают в триггер
  `$CLAUDE_PROJECT_DIR`, а заголовок и текст поддерживают подстановку
  `{project}`. Заголовок по умолчанию: `Claude Code · {project}`. Если проект
  неизвестен, подстановка убирается вместе с повисшим разделителем.
- **Уведомление «Claude ждёт разрешения»** — через хук `Notification` и второй
  триггер `~/.claude/.ntfy-trigger-waiting`. Настройки `notifyOnWaiting`
  (вкл/выкл) и `waitingMessage` (текст).

### Примечание об обновлении
Чтобы заработали имя проекта и пуш об ожидании, нужно один раз обновить хуки —
выполните команду «Claude Notify: настроить хуки Claude Code» и перезапустите
сессию Claude Code. Со старым хуком всё продолжает работать, просто без имени
проекта.

## [2.0.0] - 2026-07-23

### Изменено (ломающее)
- Расширение переименовано `claude-ntfy-toggle` → **Claude Notify** (`claude-notify`).
- Ключи настроек переименованы `claudeNtfy.*` → **`claudeNotify.*`**. После
  обновления проверьте настройки: если раньше были заданы `claudeNtfy.topic`
  и др., перенесите их значения в `claudeNotify.*`.
- ID команд переименованы `claudeNtfy.*` → `claudeNotify.*`.

Файл-триггер (`~/.claude/.ntfy-trigger`) и сам хук Claude Code **не изменились**
— их править не нужно.

## [1.2.0] - 2026-07-23

### Добавлено
- Настройка `token` — Bearer-токен для защищённых топиков на собственном
  сервере ntfy.
- Настройка `priority` — приоритет пуша (`min`…`max`).
- Настройка `tags` — теги/эмодзи ntfy через запятую.
- Настройка `click` — URL, открывающийся по тапу на уведомлении.
- Таймаут HTTP-запроса (8 с), чтобы зависшее соединение не держало сокет.
- Резервный опрос файла-триггера — на случай, если `fs.watch` пропустит
  событие или каталог `~/.claude` появится уже после запуска.

### Изменено
- Команда «отправить тестовое уведомление» теперь ждёт ответ сервера и
  сообщает **реальный** результат: успех или понятную причину ошибки
  (неверный топик/токен, таймаут, нет сети).

## [1.1.0]

- Первый опубликованный вариант: кнопка-переключатель в статус-баре и пуш на
  телефон через ntfy при завершении запроса Claude Code.
