# Changelog

Все заметные изменения расширения **Claude Notify**.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [2.1.1]

### Исправлено
- QR подписки теперь кодирует ntfy-схему `ntfy://<host>/<topic>` вместо
  `https://…`, чтобы сканирование **открывало приложение ntfy** и подписывало на
  топик, а не веб-страницу в браузере (https-ссылки на Android для запуска
  приложения ненадёжны). Для http-сервера добавляется `?secure=false`.

## [2.1.0]

### Добавлено
- Команда **«Claude Notify: показать QR для подписки»** — открывает панель с
  QR-кодом подписки. Сканирование телефоном **открывает приложение ntfy** и
  подписывает на топик (QR кодирует схему `ntfy://<host>/<topic>`, для http-
  сервера — с `?secure=false`), не нужно вводить длинную случайную строку
  вручную. QR генерируется локально (без внешних сервисов), библиотека
  `qrcode-generator` вшита в расширение.

## [2.0.0]

**Claude Notify** — уведомления на телефон о работе Claude Code (через ntfy).

### Уведомления
- Пуш при **завершении** запроса.
- Пуш при **ожидании**: когда Claude просит разрешение (хук `Notification`) или
  показывает диалог выбора `AskUserQuestion` (хук `PreToolUse`). Единый текст.
- Пуш при **обрыве** запроса (лимит токенов, `stop_reason ≠ end_turn`) —
  отдельным текстом.
- **Имя проекта** в заголовке уведомления (`Claude Code · {project}`).
- Тестовое уведомление шлёт «Тестовое уведомление».

### Надёжность
- **Точная защита от дублей** по идентификатору запроса (`prompt_id`), общая для
  всех окон VS Code (атомарный маркер), без гадания по времени.
- Устойчивое отслеживание триггеров (`fs.watch` + резервный опрос), таймаут
  HTTP-запроса, корректный UTF-8 в заголовке и тексте.
- **Индикатор здоровья** в статус-баре: предупреждает, если топик пуст или хуки
  не настроены.

### Удобство
- **Автонастройка хуков** одной командой (bash или PowerShell под систему);
  логика хука вынесена в помощник `~/.claude/claude-notify-hook.js`.
- Кнопка-переключатель в статус-баре.
- Настройки: топик, сервер, токен (Bearer), приоритет, теги, click-URL, тексты
  уведомлений, окно защиты от дублей.

## [1.0.0]

Первая версия (Claude ntfy toggle): кнопка-переключатель в статус-баре и пуш на
телефон через [ntfy](https://ntfy.sh) при завершении запроса Claude Code.
